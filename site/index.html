JavaScript + TypeScript icon system

A visual language for how code behaves.

One thin-line family for primitives, types, control flow, architecture, and agent systems. Related ideas share shapes, while easily confused ideas remain visibly distinct.

The three-part grammar

Container = thingbox, document, braces, boundary
Motion = behaviorarrow, orbit, route, branching
Badge = specializationgear, lock, clock, @, check

Composition rules

Build visual sentences, not pictograms.

One baseGive each object one dominant silhouette.
One modifierAdd at most one state or specialization badge.
Separate motionUse arrows and routes between objects, not inside a crowded glyph.
Keep labelsIcons support recognition; text owns precise meaning.

Original drawings

Every glyph is an original inline SVG on the same 24 by 24 grid. The library does not inherit another icon pack's metaphors.

Reserved symbols

Keep a straight pipe for a linear pipeline. Use a person only for a human actor. Treat a question mark as unknown or help, not data retrieval.

Drawing contract

Use rounded 1.35 to 1.5 pixel strokes, two pixels of optical padding, and lower-right modifiers. The base must remain recognizable at 16 pixels.

Accessible by default

Keep visible labels in learning surfaces. Give standalone icons an accessible name; mark icons beside equivalent text as decorative.
